# Sunday League

Минимальный прототип учёта воскресного футбола среди друзей.

**Гипотеза:** после игры кто-то за 2–3 минуты занесёт составы и персональную статистику, и таблица по людям будет понятна, даже когда одни и те же игроки каждую неделю в разных командах.

Счёт матча считается из голов. «Белые» и «Цветные» — только метки на конкретное воскресенье.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

- Сайт: http://127.0.0.1:8000/
- Админка: http://127.0.0.1:8000/admin/  (`admin` / `sundayleague`)

Сайт только смотрят. Менять игроков, аватарки и матчи может только админ (`admin` / `sundayleague`). Аватар загружается в карточке игрока в админке.
